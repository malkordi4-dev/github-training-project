## 📄 وصف المشروع
مشروع ويب متكامل لمطعم مأكولات سريعة يسمى "Feane". تم بناء المشروع كجزء من التدريب الميداني لتطبيق مهارات تطوير الواجهات الأمامية وإدارة المشاريع برمجياً. يركز المشروع على تنظيم الكود، إدارة الفروع (Branches)، وتوثيق العمليات عبر GitHub.

## 🛠 التقنيات المستخدمة
* **HTML5**: لبناء هيكل الصفحات (قائمة الطعام، الحجز، التعليقات).
* **CSS3**: لتنسيق الواجهات وجعل التصميم عصرياً ومتجاوباً.
* **Git**: لإدارة النسخ والتحكم في الإصدارات (تم تنفيذ أكثر من 5 Commits).
* **GitHub Pages**: لاستضافة المشروع ونشره بشكل مباشر أونلاين.

## ⚙️ مميزات الموقع
* **عرض المنتجات**: قائمة متنوعة للبرجر والبيتزا والباستا.
* **نظام الحجز**: نموذج تفاعلي لحجز الطاولات داخل المطعم.
* **تصميم متجاوب**: يعمل بكفاءة على جميع الشاشات (موبايل، تابلت، كمبيوتر).
